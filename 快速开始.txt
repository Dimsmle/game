Character Studio v0.9 · 快速开始
====================================

现在默认打开“角色舞台 + 对话框 + 设置按钮”的游戏模式。
选择三段无声对话之一，点击继续并在弹窗中选择回应，检查每句话的表情。
开发界面另用 10_打开开发工作台.bat；详情见 docs\V0.9_GAME_SCENES.md。

1) Windows / PyCharm 选择 Conda Python 3.11
2) 安装：
   python -m pip install -r requirements.txt

3) 先做自检：
   python main_desktop.py --doctor

4) 跑测试：
   python -m unittest discover -s tests -v

5) 查模型：
   python -u main_desktop.py --root "G:\开发游戏\Amakano3_AI" --list-models

6) 启动：
   python main_desktop.py --root "G:\开发游戏\Amakano3_AI" --model kan_10

UI 重点：
- 表情/动作：查看真实 PSB 预设，给动作打语义标签。
- 背景：本地图库、昼夜、自定义场景。
- 系统：runtime 状态、Renderer 能力、Doctor、标签导入导出、
        服装/动作家族人工元数据。

动作标签：
  %LOCALAPPDATA%\CharacterLab\animation_tags.json
模型元数据：
  %LOCALAPPDATA%\CharacterLab\model_metadata.json
聊天：
  %LOCALAPPDATA%\CharacterLab\history.sqlite3

Windows EXE：
  python -m pip install -r requirements-build.txt
  python build_windows.py

交给 Codex 前请先阅读：
