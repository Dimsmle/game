# Character Studio v0.4.2

- 修复固定仅查找 `tex-texture.png` 的错误。支持 `tex#000-texture.png`、`tex#001-texture.png` 以及更多资源页。
- 按每个 `source.texture.pixel` → `.resx.json.Resources` 确认所属 PNG。
- 每个图集独立坐标缩放，同名 icon 按 `(source, icon)` 区分。
- `--list-models` 显示已经找到的纹理数量和缺少的文件名。
- `main_desktop.py` 默认素材根路径修为 `G:\开发游戏\Amakano3_AI`。
- 已解包 `kan_10` 时优先作为新安装用户的初始角色造型。
- `desktop.py` 调试器也支持多图集模型，不再错误限制单 PNG。
- 仍属于近似静态模型组装器，不包含原版 E-mote mesh/stencil/physics。
- 测试范围：单图集 `kan_0` 真文件、合成的多图集模型；未获取 kan_10 主 JSON/resx 进行真实模型重建测试。
