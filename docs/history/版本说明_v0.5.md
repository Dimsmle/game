# Character Studio v0.5 · 场景背景图库

## 本次交付
- 新增 100% 本地背景库：扫描资产根目录内的 `image/bg/`、`assets/image/bg/` 等常见目录。
- 新增缩略图网格、搜索、点击即临时预览。
- 新增批量导入 PNG、JPG、WEBP，限制文件大小和解码尺寸，保存到用户数据目录。
- 背景与模型/服装分离；`kan_10` 多图集机制和切装保持不变。
- 新增白天/傍晚/夜晚绑定与任意自定义地点；场景选择器可即时切换。
- 新增按电脑本地时间自动切换场景，可关闭；兼容原有定时事件。
- 新增背景 Cover / Contain 适配策略，可持久化。
- 保留 DeepSeek 兼容接口、GPT-SoVITS、可选 Whisper、AI 绘图和 EXE 构建器。
- 主 JSON 与纹理仍从授权的本机解包资源读取，不包含受版权保护的资源。
- **测试：** 13 项后端单元/端到端测试通过；浏览器离线模拟交互确认背景卡片、绑定、
  自定义场景、自动昼夜和适配设置无 JS 异常；真实 Windows WebView2/EXE 尚待测试。

## 已知限制
- 尚未还原原生 E-mote 的完整网格变形、服装遮罩、物理模拟和连续动作。
- 没有实际用户上传的 kan_10 JSON/resx，穿衣模型的最终显示仍需本机验收。
- 背景图库只有在你本机放入或导入背景图片后才出现游戏画面；不会联网下载版权内容。
- 不会根据 `bg01aa` 等编号猜测哪个是白天、傍晚或夜晚。
- 当前自动昼夜时间固定：07:00–17:00 day，17:00–19:00 evening，其余 night。
