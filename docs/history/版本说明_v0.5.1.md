# Character Studio v0.5.1 · 真实 E-mote 表情及动作预设修复

针对上传的 `kan_10.json` / `kan_10.resx.json` 进行结构核对，确认：
- 128 条 timelineControl = 108 组面部表情（3×36）+ 20 组动作。
- `普通Ａ` 预设 `face_tears=0`，`泣くＡ` 是 `face_tears=1`。
- 旧版绘制未来 keyframe 的 bug 导致中立脸显示了未来帧的左右泪水；已修复。
- 普通/开心/惊讶/悲伤眼部 sprite 图块都可能不同，不应统一为中立眉眼。
- `face_eye_open=0/10/20/31..50` 含义不同，移除固定的错误 `38` 眨眼。
- 前端新增完整 128 预设搜索与分组选择，点击即可渲染当前模型。
- 新增 20 套动作时间轴在指定时间帧的参数插值和近似静态预览。
- 渲染结果按模型+预设+采样帧+源文件签名分别缓存。
- TTS 与眨眼使用当前表情派生图，不再重置为普通脸。
- 保留上一版背景管理、模型换装、接口和 EXE 构建脚本。

本次不能声称完整还原原版动态动画：mesh、stencil、physics、非线性插值仍未实现。
`kan_10` 的匹配 `tex-texture.png` 目前未收到；真实游戏贴图的视觉最终验收仍需用户本机完成。
