# v0.4.1 更新

- 修复 `kan_0` 硬编码：新增已解包 `kan_N` 模型自动发现。
- 交互界面顶部新增模型选择器和“加载造型”按钮。
- 模型缓存分离：各型号分别存储六张静态近似图和缓存元信息，避免覆盖。
- 支持 `--model kan_1` 和 `--list-models`。
- 记忆上次模型选择，保留用户已调整的角色图层位置和缩放。
- 添加路径/型号白名单，不能通过 API 切换到任意系统路径。
- 添加 `.gitignore`，减少 GitHub 误上传游戏资源与密钥的风险。
- 真实服装素材**未包含在本包中**；所需部件是否存在取决于选用的原始 PSB。
- 完整原版 E-mote 动态网格/遮罩/骨骼仍待实现。

## 测试
通过两套自己生成的模拟 PSB JSON+PNG 端到端验证：
- 初次渲染，缓存命中，六状态文件；
- API 查找两个模型、切换模型，图像资源即时可读取；
- 非法文件路径拒绝；
- 原有静态合成单元测试。

本发布包只包含代码和说明，不包含游戏原始资源。
