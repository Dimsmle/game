# Character Studio v0.8 本地开发与验收记录

日期：2026-10-15。基于 v0.7 原架构继续实现，未重写聊天、行为标签或状态机。

## 交付范围

- 修复 `type: 0` sprite 区间终止标记，解决 kan_10 普通/笑脸保留水滴叠层的问题。
- 新增独立 CPU Bezier 网格适配：读取 resx 的 `ExtraFlattenArrays`，对 4×4
  控制点按 `head_UD` 插值，按节点层级组合变形，再生成透明角色帧。
- 首个连续动作只支持 `うんうん`，不是完整原生 E-mote。其余动作保留静态采样。
- 真实 kan_10 的笑脸点头：源时间轴 118 个 1/60 秒单位，输出 49 帧，44 个不同画面，
  目标播放 24 FPS，普通/眨眼/说话每帧各一张，透明背景。
- 前端 `FrameSequenceRenderer` 按时钟定位帧；支持停止/新动作打断、口型优先、
  眨眼、结束恢复同一表情，并限制解码缓存最多 15 张，不加载全部帧常驻内存。
- 生成在单后台线程进行；UI 可轮询进度和停止等待，已有缓存立即复用。
- 每个模型、表情、素材签名分别验收；只有用户在 UI 勾选验收的序列才用于对话。
  验收绑定签名，素材改变后需要重新生成与验收。
- Renderer 适配器会优先选择已验收的 `うんうん`，避免同标签的 `はい` 静态预设抢先。
- 状态机新增动作开始/结束事件及 token 校验；旧回调不会终止新动作。
  手动覆盖清空旧动作队列，同时保留正在播放的语音。
- 修复启动尚未完成就发送对话的竞争；修复小窗口下舞台裁切，增加放大舞台。
- 资源列表跳过内部帧缓存子目录，避免大量生成帧淹没原素材。
- 启动脚本优先使用项目 `.venv`；提供只打包源码的发布脚本。

## 本机使用

本机已配置 `.venv`，包含 Python 3.12、Pillow、pywebview。双击 `01_启动完整角色桌面程序.bat`，
或运行：

```powershell
.\.venv\Scripts\python.exe main_desktop.py --root "G:\开发游戏\Amakano3_AI" --model kan_10
```

进入「表情/动作」，选 `笑顔Ａ`，点击「连续预览点头 · 24 FPS」。
播放时可点击「预览说话口型」与「停止预览」。检查画面后勾选
「已检查当前表情的点头，允许对话使用」。在离线演示对话中输入「请点头」即可验证行为链路。
还没验收的其它表情不会自动使用这套笑脸序列，也不会被强制切成笑脸。

首次生成在本机约需半分钟，后续复用。取消等待后，正在生成的后台缓存仍会完成。
可通过命令预先生成：

```powershell
.\.venv\Scripts\python.exe main_desktop.py --model kan_10 --export-nod --probe-expression "笑顔Ａ"
```

生成文件在素材目录 `character_exports/sequences/`；验收记录在用户数据目录
`%LOCALAPPDATA%\CharacterLab\sequence_reviews.json`。原始 PSB、PFS、JSON 和纹理均未改写。
开发 UI 验收使用独立临时数据目录，没有把开发验收勾选写入用户的正式配置。

## 未完成与路线边界

- 这里只实现了 `head_UD` 的有限 Bezier 网格预览；E-mote 完整 mask/stencil、物理、
  其它组合类型、非线性控制和其它动作仍需继续实现。
- 点头有了真实数据驱动的局部变形，但画质不等同游戏原运行时；最终审美验收由用户决定。
- FreeMote.NET 测试能够初始化设备，但创建 kan_10 播放器时异常退出，控制台无法格式化异常。
  官方源码 README 限定它用于 Pure PSB，故当前只能确认存在输入兼容性问题，不能确定是加密。
  未尝试密钥、解除保护或替换游戏 DLL。
- 临时 `NativeSmoke.exe` 曾触发杀毒告警，已停止使用；它、下载的研究源码、任何 DLL/EXE
  都不在发布包中。该告警没有被认定为误报，也没有添加白名单。
- 用户目前没有部署 AI。角色预览无需 AI；真正对话可接 DeepSeek 或其它 OpenAI 兼容 API，
  声音可选 GPT-SoVITS。当前没有真实服务地址/模型配置可供效果联调，不下载模型或猜测声音权重。
- 本次交付源码版和可运行 Python 桌面环境，未交付新的 Windows EXE；现有打包脚本保留。
- Live2D 分层 PSD/rig 与透明桌宠不在本次交付范围。
