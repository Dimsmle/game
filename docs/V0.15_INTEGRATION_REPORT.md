- `studio/gameplay_catalog.py`：现有数据库中的地点/媒体/触摸/事件目录；迁移前 SQLite 备份、修订校验、内容哈希绑定。文件名不等于审核。
- `studio/gameplay.py`：合法候选提示词、最后一句/TTS 完成确认、玩家选项、预加载后提交、CG 播放租约、自动时段门控、透明像素排除与触摸语义输入。
- `studio/game_db.py`：由既有 GameStore 单事务写入选择、属性、日记、场景与解锁；幂等、版本/档案 generation 防护；拒绝无惩罚。
- `studio/app.py`、`main_desktop.py`、`game_state.py`、`replies.py`：接入现有流式链路，不替换原存档、密钥、人设和渲染器。
- `studio/roleplay_plus/bridge.py`、`composer.py`：同一 PromptComposer 注入真实已提交场景/日记和合法候选；检查器可看到候选 ID。
- `studio/web/gameplay.html`、`gameplay_ui.js`：主服务的本地审核界面，地点/时间、媒体适用角色、事件规则、命中区编辑和日记。
- `studio/web/gameplay_stage.js`、`game.js`、`app.js`、`reply_player.js`、`index.html`：舞台选项、已解锁媒体、手动锁/自动时段、触摸、完成 ACK 和取消隔离；原逐句表情/点击显示完整句保留。
- `studio/roleplay_plus/web/`：设置页增加审核入口；Prompt 检查器改用 HTML 确认框，避免原生 confirm 在 WebView 中挂起。

三个初始事件仅是本地规则（休息/爱好/鼓励），不是固定台词玩法；默认主动事件和触摸关闭。AI 只提议事件 ID，不能自行写属性。
